# Hw2-EWD

## Study Group and Peer Tutoring Hub

The chosen topic for HW1 was Study Group and Peer Tutoring Hub.
This is HW2, an extension of HW1, including responsive design, improved CSS, a Figma authentication UI, and a chatbot for interaction.

## Repository Structure

- index.html - Homepage  
- about.html - About us  
- overview.html - Responsive overview page with Grid + Flexbox  
- data.html - Table with study group and tutor schedules  
- chatbot.html, chatbot.css, chatbot.js - Interactive chatbot  
- contact.html - Contact/feedback form  
- card.html, card.css - Business card page
- car.png - Image used for the business card page  
- overview.css - CSS for overview page  
- style.css - Main stylesheet
- figma.png - Image which represents the Figma authentication UI 
- figma-auth.css - Exported CSS from Figma authentication UI  
- proof.png - Screenshot showing reusable styles in Figma  
- specificity.html, specificity.txt — CSS specificity exercises
